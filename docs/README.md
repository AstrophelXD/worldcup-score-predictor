## 阅读顺序建议

1. 先看 `constraints.md`，统一预测口径、数据边界和反泄漏规则。
2. 再看 `system-design.md`，了解整体架构、数据模型、特征与模型方案。
3. 看 `mvp-task-list.md` 了解 MVP 范围与验收标准。
4. 按 `coding-plan.md` 分阶段实施，勾选 Todo 推进编码。
5. 面向 **2026 实战** 时阅读 `world-cup-2026-playbook.md`（数据清单、预测账本、回滚与报告口径）。
